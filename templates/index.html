Point 1: Real-World Problem Network Security

IoT microcontrollers (ESP32) and edge gateways face volumetric DDoS flooding, rogue botnet transmissions, and sensor outages that overwhelm buffer memory and exhaust bandwidth.

Point 2: Mathematical Goal Numerical Methods

Construct a lightweight, ultra-fast online detection algorithm in pure Python using numerical differentiation for rapid impulse detection and least-squares regression for baseline drift tracking.

Point 3: Resources & Setup Zero ML Stack

Zero reliance on heavy machine learning or external math libraries (no NumPy, SciPy, or scikit-learn). Runs on resource-constrained embedded systems and standard laptops.

Point 4: Data & Discrete Sampling Δt = 1.0 s

Discrete time-series packet counts measured per second $y(t_i)$. Normal traffic exhibits smooth diurnal oscillations (45–75 pkt/s) plus bounded environmental jitter.

Point 5: Method A Math Finite Differences

Calculates 1st-order backward difference $y'_{1st} = (y_i - y_{i-1})/\Delta t$ and 3-point backward difference $y'_{3pt} = (3y_i - 4y_{i-1} + y_{i-2})/(2\Delta t)$ with truncation error $O(\Delta t^2)$.

Point 6: Method B Math Least Squares Fit

Fits linear model $\hat{y} = a_0 + a_1 t$ over sliding window of $N=20$ samples by minimizing sum of squared residuals $S_r = \sum (y_k - \hat{y}_k)^2$ solving Normal Equations explicitly in raw loops.

Point 7: Parameter Justification τd=35, τr=28

$\tau_d = 35$ pkt/s² safely ignores natural network jitter ($< 15$ pkt/s²) while triggering instantly on DDoS surges. $\tau_r = 28$ pkt/s allows normal diurnal drift without false positive alarms.

Point 8: Anti-Corruption Logic Window Stability

When an anomaly occurs, the raw spike is excluded or clamped to $\hat{y}$ in the regression window. This prevents baseline poisoning where attacks pull $\hat{y}$ upward and trigger post-attack false drops.

Point 9: Verification & Benchmark 50 Held-Out Samples

Deterministic reference dataset comparing Finite Difference formulas with exact analytical derivatives $y'_{true}(t)$, calculating Truncation Errors, Confusion Matrix, and F1-score.

Point 10: Combined Practical Decision Rule & Automated Action Firewall Mitigation

Synthesis: When both $|y'| > \tau_d$ and $e > \tau_r$ (or severe 1.5x breach), the system executes automated mitigation (rate-limiting iptables rule or packet drop alert). If only one threshold is breached, a WATCH warning is posted without interrupting traffic.

MATH 301 Project AI39: Complete Academic Specification

1. Numerical Differentiation (Finite Differences)

Discrete packet rates sampled with uniform step Δt = 1.0 s.

1st-Order Backward Difference: y'_{1st}(t_i) = [ y_i - y_{i-1} ] / Δt (Error: O(Δt))
3-Point Backward Difference: y'_{3pt}(t_i) = [ 3·y_i - 4·y_{i-1} + y_{i-2} ] / (2·Δt) (Error: O(Δt²))
Central Difference (Offline): y'_{central}(t_i) = [ y_{i+1} - y_{i-1} ] / (2·Δt) (Error: O(Δt²))

2. Linear Least Squares Regression

Minimizes the sum of squared residuals Sr over sliding window of N observations:

S_r = ∑ [ y_k - (a_0 + a_1·t_k) ]²
Normal Equations:
  N·a_0 + (∑ t_k)·a_1 = ∑ y_k
  (∑ t_k)·a_0 + (∑ t_k²)·a_1 = ∑ t_k·y_k
Closed Form: a_1 = [ N∑(ty) - ∑t∑y ] / [ N∑(t²) - (∑t)² ], a_0 = (∑y - a_1∑t) / N
Window Standard Error: σ_{est} = √[ ∑(y_k - ŷ_k)² / max(1, N - 2) ]

3. Anti-Corruption Sliding Window Shield

Standard least-squares fitting is vulnerable to high leverage outlier corruption: a massive DDoS attack would drastically inflate the fitted slope a1 and intercept a0. When the attack finishes, normal traffic would be mistakenly flagged as severe negative drops.

Our Solution: The training buffer dynamically replaces detected anomaly points with their uncorrupted baseline prediction ŷi, ensuring clean mathematical reference across arbitrary attack durations.
